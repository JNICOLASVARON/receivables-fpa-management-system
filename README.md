# Receivables Operations & FP&A Management System

An Excel/VBA-based operational analytics and FP&A system designed to standardize receivable data, support settlement and collection workflows, analyze portfolio performance, and translate operational activity into monthly financial reporting and forecasting.

## Project Overview

The project integrates:
- Operational data standardization
- Receivable purchase and return analysis
- Settlement and collection workflows
- Law-firm performance analysis
- Operational dashboarding
- Monthly financial reporting
- Forecast vs Actual analysis
- Rolling full-year forecasting
- EBITDA, EBIT and cash-flow analysis

## Key Components

### Operational Data
Centralized and normalized receivable-level data used across the model.

### Reduction Calculator
Case-level settlement, allocation, negotiation history, and collection tracking.

### Operational Dashboard
Portfolio-level monitoring of case distribution, collections, recoveries, and law-firm performance.

### Monthly Financials
Monthly and quarterly financial reporting, forecasting, variance analysis, profitability, and cash flow.
